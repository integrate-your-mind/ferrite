# Code of Conduct

## Be respectful and clear

Ferrite is an open-source community project. All contributors and participants should:

- Be welcoming and kind.
- Assume good intent and ask for clarification when uncertain.
- Critique code and ideas, never people.
- Keep discussions focused on reproducible facts and evidence.
- Treat personal information as private.
- Reject harassment, threats, and discriminatory behavior.

## Participation

If behavior is disruptive or unsafe, moderators may remove comments or restrict participation.
