# Security Policy

## Supported versions

Public, source-available releases are experimental. Use production workloads only after your own validation.

## Reporting a vulnerability

If you find a security issue, report it privately by emailing:

- security@integrate-your-mind.com

Include:
- component(s) affected
- impact scenario
- minimum reproduction steps
- recommended fix if known

We will triage and respond with a plan and timeline.

## Scope

Please report issues that involve:
- auth or action replay behavior
- protocol parsing, transport, or manifest validation
- code execution, filesystem/path escapes, or untrusted inputs
- supply-chain, package, or publish pipeline risks

Please avoid posting tokenized reports publicly until reviewed.
