## Reproduction and fix

The compiler-owned graph previously treated extensionless `.mts`, `.cts`, `.mjs`,
and `.cjs` files and directory indexes as valid candidates. A direct probe against
the installed production esbuild dependency proved that extensionless `.tsx`,
`.ts`, `.jsx`, and `.js` resolve, while all four M/C variants fail with
`Could not resolve "./dep"`. Ferrite's server bundler uses the same four
extensionless candidates.

The production regression initially failed with `Missing expected rejection`,
proving `build-client.mjs` incorrectly emitted a successful graph. The resolver now
uses the shared four-extension list only for extensionless file and index searches.
Explicit `.mts`, `.cts`, `.mjs`, and `.cjs` imports remain supported, including
`.mjs -> .mts` and `.cjs -> .cts` source substitution.
