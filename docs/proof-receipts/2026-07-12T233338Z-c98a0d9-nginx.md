## Failures found before proof

1. The first live `nginx -t` run exposed deprecated `listen ... http2` syntax; the template now uses the nginx 1.25.1+ `http2` directive.
2. Live authority probes showed that the prior template returned `200` for unknown and mismatched absolute-form authorities.
3. Independent review showed that `$host` canonicalization also accepted malformed raw Host ports and absolute-form ports. Raw Host and raw request-target maps now reject those inputs with `421`.
4. The first Node TLS harness used `socket.end(payload)` and observed empty responses. It now writes the request and lets the explicit close/deadline contract finish the exchange.
5. The first verifier asserted only client-visible statuses. The final verifier requires parsed upstream JSON logs, proves trusted-proxy client-IP policy is active, and rejects smuggling canaries. Synthetic injection proved that assertion is not vacuous.
