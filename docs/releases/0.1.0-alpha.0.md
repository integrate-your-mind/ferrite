# Ferrite 0.1.0-alpha.0 candidate

This is a candidate release note, not evidence that the version has been
published.

## Package set

- `@ferrite/protocol`
- `@ferrite/protocol-wasm`
- `@ferrite/runtime`

The candidate intentionally excludes `@ferrite/node` and native prebuild
packages until the complete declared target matrix is built, independently
reviewed, and registry-tested.

## What is available

- Rust-owned routing, rendering, artifact construction, protocol validation,
  and bounded production serving in a source checkout.
- TypeScript JSX, DOM, server, navigation, and protocol-facing APIs.
- Deterministic package construction, clean local tarball installation, browser
  tests, and source-backed example applications.
- Strict private-upstream HTTP framing and bounded request, action, streaming,
  cancellation, and shutdown behavior.

## Developer-preview boundary

Ferrite is experimental and is not a drop-in React or Next.js replacement.
Expect breaking APIs and incomplete compatibility.

This package release does not include a public Rust CLI binary, managed
hosting, broad native prebuilds, or a production support commitment. Use the
repository's source onboarding workflow for complete application evaluation.

## Known gaps

- The self-hosted Buildkite topology cannot currently produce npm provenance.
- Registry ownership, npm 2FA, and clean registry installation must be proven
  before publication.
- `@ferrite/node` has only macOS arm64 package proof at this candidate.
- Hosted deployment and multi-platform native runtime proof remain separate
  gates.

## Rollback

Do not overwrite this version. If it is defective, publish a corrected
prerelease, move the `next` dist-tag only after verification, and deprecate the
broken exact version with a replacement message.
