# Milestone 090 Proof

Status note: milestone 091 subsequently fixed the Cargo workspace packaging failure recorded below.

## Scope

Production review remediation: normalize dynamic server-action route patterns, require the real example integration path in `pnpm test`, bound socket admission and client-bundler execution, redact public subprocess errors, and harden supplied proxy/container defaults.

## Reproduced Failure

Before the route fix, `pnpm build:example` failed because the real example declared `/posts/:id` while the TSX runner inferred `/posts/[id]`. The previous default build/test gates did not execute this path.

## Implemented

- The TSX runner converts `[id]`, `[...slug]`, and `[[...slug]]` into the same `:id`, `*slug`, and `*slug?` patterns generated by the Rust router.
- `pnpm test` now runs static example build, render fixture, dev one-shot, and production serve one-shot.
- The production worker pool counts active and queued sockets and returns `503` at the configured limit.
- The production renderer deadline also bounds client-bundler subprocesses.
- Production subprocess failures return generic `500` or `504` HTML and retain details on server stderr.
- Trusted forwarded-client-IP selection matches standard `X-Forwarded-For` chains; nginx overwrites the edge header.
- Nginx blocks public metrics proxying, the directly exposed container leaves metrics disabled, and Docker/Git ignore common env/key files.

## Local Proof

- `pnpm lint`
- `pnpm typecheck`
- `pnpm build`
- `pnpm test` with loopback and Chromium permissions
- `pnpm release:verify:npm`
- `git diff --check`

The example gate produced 9 HTML files, 9 client bundles, 2 server-action manifests, and no skipped dynamic routes. All four Chromium tests passed. The release verifier packed and clean-installed all four JS-facing packages.

## Explicitly Not Proven

- Remote CI, push, or PR.
- Hosted staging or container/proxy runtime after these changes.
- Cargo workspace packaging; it currently fails on unversioned internal path dependencies.
- Immutable artifact-backed production serving, parallel route execution, or response-write deadlines.
- Browser-to-real-production-server action and payload integration.
