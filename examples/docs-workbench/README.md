# Ferrite Docs Workbench

Docs Workbench is a real source-checkout example for evaluating Ferrite's server-first application boundary. It demonstrates a custom document, a root layout with one small `use client` chrome island, a static catch-all guide route, and a dynamic reference route with generated metadata.

## Run from the repository checkout

The public Ferrite CLI and registry packages are not available yet, so run this example from the repository root with the locally built CLI and workspace dependencies:

```sh
pnpm install
cargo run -p ferrite-cli -- check --project examples/docs-workbench
cargo run -p ferrite-cli -- dev --project examples/docs-workbench
cargo run -p ferrite-cli -- build --project examples/docs-workbench
cargo run -p ferrite-cli -- serve --project examples/docs-workbench \
  --artifact .ferrite/build \
  --page-renderer packages/runtime/bin/render-artifact.mjs
```

The artifact path is relative to `--project`, so the repository-root command
uses `.ferrite/build` rather than repeating `examples/docs-workbench`.

The app has no environment variables, database, model, or external service. It uses only source files and Ferrite's generated artifact directory.

## Routes

- `/` — server-first overview with a hydrated menu button.
- `/guides/getting-started` and `/guides/architecture` — known static paths generated by `generateStaticParams`; other catch-all paths render from the route parameter without claiming to be pre-rendered.
- `/reference/runtime` and `/reference/router` — generated static examples of a dynamic route with `generateMetadata`; unknown ids remain dynamic and are labeled experimental in metadata.

## Verified limits

This example is a framework evaluation surface, not a production documentation deployment. It does not provide public package installation, a database-backed CMS, full React Server Components compatibility, automatic `use server` discovery, or hosted CI proof. The client boundary is intentionally limited to the navigation chrome; no unsupported SPA navigation is implied.
