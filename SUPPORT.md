# Support

Ferrite is an experimental, source-build developer preview. There is no public
SLA, compatibility guarantee, managed hosting, or production incident response
commitment.

Supported evaluation is limited to pinned revisions used for local research,
documentation, dashboards, content-heavy prototypes, and framework proof apps.
Reports should include the exact commit, build ID, deployment topology, logs,
and a minimal reproduction.

Use GitHub Issues for reproducible defects and focused feature discussions. Use
GitHub Discussions for general evaluation and usage questions. Security reports
must follow `SECURITY.md` and must not be posted publicly.

Public production use, authentication-sensitive mutations, file uploads,
multi-process replay guarantees, managed hosting, and React Flight compatibility
remain outside the current support boundary.
