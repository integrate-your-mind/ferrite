# Support

Ferrite is available only as a support-capped private alpha for trusted design
partners. There is no public SLA, compatibility guarantee, managed hosting, or
production incident response commitment.

Supported evaluation work is limited to pinned revisions used for internal
documentation, dashboards, content-heavy tools, and framework proof apps.
Reports must include the exact commit, build ID, deployment topology, logs, and
a minimal reproduction.

General questions and defects may use repository issues. Security reports must
follow `SECURITY.md`. Public-production, auth-sensitive mutation, upload,
multi-process replay, or React Flight compatibility requests are outside the
current support boundary.
